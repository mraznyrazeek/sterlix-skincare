# Skincare Coming Soon — React Starter

A premium, feminine, Korean-beauty-inspired coming-soon landing page built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Project structure

```text
skincare-coming-soon/
├── index.html
├── package.json
├── README.md
└── src/
    ├── App.jsx
    ├── data.js
    ├── main.jsx
    └── styles.css
```
